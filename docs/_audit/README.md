# Fleet audit artifacts

Generated by the SEYU fleet documentation audit (messmass#344/#345/#346).

- `fleet-architecture.md` — **canonical** code-verified map of how all five
  systems connect (messmass, camera, fanmass, try-on, SSO). The other three
  repos point here.
- `drift-register.md` — messmass doc/comment verdicts (WRONG/STALE/MISSING/
  CURRENT) with file:line evidence.
- `endpoints.json`, `collections.json`, `env.json`, `outbound-hosts.json`,
  `docs.json` — generated inventories; the denominator for coverage claims.
  Regenerate with `python3 scripts/fleet-audit-inventory.py --write`; CI runs
  `npm run inventory:check` (`--check`) and fails on drift (messmass#355).
- `contract-first-rule.md` — the fleet rule: a cross-app surface change updates
  its contract doc and the inventories in the same commit.
- `scripts-keep-list.md` — how the 2026-09-08 `scripts/` prune (messmass#352)
  decided what stays; add new scripts through `package.json` or a current doc.

These files are intentionally header-less so the docs:audit version gate does
not bind them to a version they are not about.
